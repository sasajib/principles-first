# Courses

Generated output. A course lands here as `courses/<slug>/` when you run `/course <topic>`.

Everything under this folder except this file is ignored by git: the repository is the plugin, and the
courses it produces are yours, not the plugin's. If you want to publish a course, remove the
`courses/*` rule from `.gitignore` in your own fork.

`course.json` inside each course folder is the manifest the checker reads.
